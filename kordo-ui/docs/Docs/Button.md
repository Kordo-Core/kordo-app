
1. Couleur (color)

- primary → couleur principale de la marque
- secondary → couleur secondaire
- black → fond noir / texte blanc

2. Inversé (inverted: boolean)

- false (par défaut) → bouton rempli (fond = couleur choisie, texte = blanc, bordure = transparente).
- true → bouton inversé (fond = blanc, texte = couleur choisie, bordure = couleur choisie).

3. Bordure (border)

- rounded → coins arrondis (ex: 9999px ou 8px selon ton style)
- square → coins carrés (0px radius)

4. Taille (size)

- normal → hauteur standard (ex: 40px)
- large → plus haut (ex: 56px)

5. Largeur (width)

- min → largeur minimale (s’adapte au contenu, padding interne seulement)
- medium → largeur fixe intermédiaire (à définir, ex: 200px)
- full → prend 100% de la largeur dispo
